# 验收与生命周期

安装成功不等于验收通过。让员工在真实 DSH 页面检查，不能用编译成功或静态截图代替业务验收。

## 功能状态

1. 首次进入有加载反馈；断网刷新显示“连不上”，不是一直转圈或空白。
2. 无记录和筛选不存在的值显示明确空状态；`delivery=digest` 显示摘要不可用提示，不伪装成空结果。
3. 长字段截断或换行，不撑破表格；错误信息可读且不泄露员工卡、令牌或内部堆栈给普通员工。
4. 连续点两次刷新不重复数据，旧响应不覆盖新响应；切换范围后结果与标题一致。
5. 无权限、数据服务缺失和渲染异常都有可见错误与可操作的下一步。

## DSH 原生视觉与布局

- 与原生页面同屏检查字体、字号、字重、行高、控件高度、边框、圆角、留白和颜色；不能出现另一套设计风格。
- 使用 DSH token 与品牌主色，不用大面积高饱和渐变、厚重阴影或刺眼多色图表。
- 页面标题 16px，正文/卡片标题 13px，辅助与表格 11–12px；常规控件高 28px；卡片细边框和 8–12px 圆角。
- 缩短窗口到约 500px 高，插件根节点可以纵向滚动并能到达最后一个区块；窄窗口可横向查看表格/图表，主页面不横向溢出。
- 切换浅色和深色模式，文字、边框、卡片、图表和错误状态仍有足够对比度，不能写死白色背景破坏深色模式。
- 检查加载、空、错误、正常、截断五种状态及连续刷新后的视觉稳定性。

每种模板追加两条业务专属检查，例如趋势图的双轴单位与月份顺序、列表筛选与列宽、工作台字段标签与空值。每次交付后给 3–5 个具体选项，例如加字段、改分组、加搜索或就这样。

## 生命周期

试制 30 天。第一次续期自动到共 60 天，第二次填理由到共 90 天，不允许第三次。到期默认私有常驻；私有位最多 10 个，满员时先下线其他插件。连续 90 天未打开会下线。只有分享/上线需要人工审批，私有制作和改声明需升级版本并重新签名。离职或手动下线后停止安装与取数，源码保留。
